# Roadmap

SPP is an experimental protocol project. This roadmap describes validation work, not adoption commitments.

## Phase 1 — public experimental release

- Publish the SPP 0.1.0 Experimental Preview for external review.
- Reproduce the Core and Admission demos independently.
- Collect schema and terminology feedback.
- Stabilize the vocabulary for requirements, evidence, and profiles.

## Phase 2 — implementation validation

- Add a second embodiment adapter.
- Explore ROS 2/Nav2 integration.
- Explore Open-RMF interoperability.
- Define an attestation and evidence-provider interface.
- Build an interoperability test suite.

## Phase 3 — broader interoperability

- Demonstrate multiple independent implementations and vendor-neutral flows.
- Provide conformance tooling and fixtures.
- Engage standards and open-source communities for technical review.
- Refine protocol versioning based on implementation feedback.

These items are research directions. They do not promise adoption, certification, production security, or participation by any particular organization.
